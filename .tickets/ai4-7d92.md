# 落地 dead 终态与重试上限

## What to build

让失败的派发有终点。现在 `DISPATCH_DEAD` 只被 import、从未写入，`max_attempts` 只被读入配置、从不比较，失败会无限重试。

规格见 [`2026-10-26-handoff-coordinator-dispatch-defect-fix-design.md`](../docs/superpowers/specs/2026-10-26-handoff-coordinator-dispatch-defect-fix-design.md)。

## Notes

- `dead` 不自动重放。指标的达成条件是「不再无限重试」，重放需要人工判断，此时代码能做的判断都已经做完了。
- 三处默认值不一致比数值本身更麻烦：运维照 README 配，行为却不同。改的时候一起改。
- 重试间隔用既有退避配置（初始 1s、指数、封顶 60s），本票不改退避策略。
