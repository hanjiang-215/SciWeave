# 提供 LLM-Wiki 看板只读快照来源

在现有 LLM-Wiki 正式查询和资源资格边界内增加只读看板片段端点，投影正式 Wiki 文档、精确 ResourceVersion 资格、候选 Proposal 状态和观测事实，供 dashboard-api 通过 HTTP 读取。不复制或修改 Wiki 正文，不把候选/待审内容显示为正式内容。

## Design

复用 WikiFormalQueryService、ResourceReviewService 和现有环境配置，使用 Python 标准库回环 HTTP seam；端点只返回 DashboardSnapshot 的 Wiki fragment（wikiDocuments/wikiCandidates/events/observedAt/sourceStatus），资源资格必须保留精确版本 ID 和范围。错误返回安全 reason_code，地址/端口环境变量配置。

## Acceptance Criteria

只读端点能返回 available 正式文档、精确引用资格和候选治理状态；正式查询不可用或资源资格未知时保留显式状态；不提供任何写入方法；使用临时 SQLite/Fake TerminusDB 和临时端口测试成功、无正式内容、资格待确认、不可用和安全错误；现有 LLM-Wiki 全量测试保持通过。
