# 提供 Harness 配置指导与 Windows 能力声明

依据工具包项目级部署与 Harness 导出设计规格，为导出结果提供不含秘密的配置指导，并按能力而非平台整体声明 Windows 支持。

## Design

Blocked by 声明式清单与 Harness 导出器。Harness 不支持项目级注册或自动执行时只提供人工步骤；无用户确认或 Harness 授权不得代为复制代码、写 .env、注册或启动服务。

## Acceptance Criteria

- [x] configuration.md 只列环境变量名称、用途、必填条件、来源、设置步骤和验证步骤，不包含真实值。
- [x] 输出明确说明 Harness 自行注册 Skills/MCP，不改写 .dsh、.cursor、全局 MCP 或用户级 Skill 配置。
- [x] Windows 平台能力逐项标记 supported/manual/unsupported/unverified，未验证的 Task Agent 后台服务不会显示为成功安装。
- [x] Harness 无副作用执行能力时只输出人工操作建议；文档区分已验证、未验证和暂不支持步骤（见 sci-weave/toolkits/WINDOWS.md）。
- [ ] 覆盖路径含空格、环境变量冲突和无凭据输出的 Windows 测试或验证记录。
