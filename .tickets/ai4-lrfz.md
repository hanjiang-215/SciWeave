# 实现 Web 看板只读聚合 API 与来源适配器

在 sci-weave/centre-control/dashboard-api 建立独立 Python 只读服务，为 Web 看板提供 GET /api/dashboard/snapshot。服务通过环境变量配置的来源 URL 读取 Research Mapping、LLM-Wiki、Gateway 和消息监听服务片段，使用标准库并行聚合，来源缺失/超时/格式错误时保留可用数据并标记 partial/unavailable，不直接访问任何私有 SQLite、TerminusDB、Redpanda 或运行时文件。

## Design

采用 Python >=3.11 + uv + 标准库 http.server/urllib，独立 pyproject.toml、uv.lock、src/main.py、src/dashboard_api/、tests/、.env.example。定义来源片段 JSON 契约与统一 DashboardSnapshot；只暴露 GET 和最小 /health，拒绝写入方法；所有地址、端口、超时、来源 URL 和可选 fixture 路径均由环境变量配置。

## Acceptance Criteria

- [x] 完成独立 Python 子项目和锁文件；`GET /api/dashboard/snapshot` 能聚合配置来源、保留来源观测时间和错误事实、在部分失败时返回 partial
- [x] 未配置来源时安全返回 unavailable 来源而非 500；超时、非 JSON、非 2xx 和未知字段不泄露堆栈/令牌
- [x] OPTIONS/GET CORS 与健康探针可配置；POST/PUT/PATCH/DELETE 不产生写入
- [x] 单测覆盖聚合成功、部分失败、超时、格式错误、无来源和安全错误
- [x] `uv sync --locked`、unittest、compileall 全部通过；记录依赖来源、用途、许可证和验证命令
