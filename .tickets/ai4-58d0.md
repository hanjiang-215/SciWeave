# 研究员的 task-agent 套件在出厂入口上不可运行

deploy-task-agent 的 service-template 与 runtime 对不上：草稿箱写入器只有 write(target_id, payload)，而 runtime 与 workflows 调 create_draft，实测抛 AttributeError；handle_inbound 的 finally 无条件 mark_processed，失败的消息被标成 processed 永不重放。gateway/mcp 与 worker 的 main.py 仍是 print 占位，docs/data-flow/work-agent.md 要求的六个处置面工具一个都没有。

## Acceptance Criteria

统一草稿写入器接口（或让 runtime 调 write），并把 mark_processed 移到 run_one 正常返回之后。|gateway/mcp 提供 query_execution/list_pending/cancel_execution/answer_question/review_execution/health 六个工具，或从 systemd 单元与文档中移除该角色。|新增测试：草稿箱不可用时 inbox 行保持 queued 并可被 drain_queued 重放。|验证命令与结果回写本票。
