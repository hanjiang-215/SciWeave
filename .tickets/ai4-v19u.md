# Agent 套件接入与协作边界分支

厘清 Agent 套件（MCP、Skills、Hooks/extensions）在 SciWeave 中的职责、接入方式和协作边界。按用户要求先建立讨论入口，后续再逐步收敛；本工单不预设技术方案。

## Acceptance Criteria

形成可供后续规划使用的套件边界与职责规格，至少明确平台提供能力与用户自带能力的分工、与端侧 Agent/消息协作及治理流程的接口边界；具体实现和依赖选型另行决策。
