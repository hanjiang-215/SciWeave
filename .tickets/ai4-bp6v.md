# 复核三张已关闭但验收未勾的调用账本工单

## 问题

留痕共享包的 `ai4-re4t`、`ai4-yzdd`、`ai4-zk0g` 三张票状态都是 `closed`，但验收项一条都没勾：分别 5、5、6 条，全空。三张票的 Notes 都写着「14 passed」。

实测确认 Notes 没撒谎，只是勾选没做：

```
cd sci-weave/centre-control/shared/audit-trail
PYTHONPATH=src .venv/bin/python -m pytest tests -q
14 passed in 0.03s
```

`tests/test_audit_trail.py` 里 14 个用例的名字与三张票的验收项能一一对上（`test_query_filters_and_stable_reverse_order`、`test_begin_and_finish_share_call_id_and_close_unfinished_call`、`test_finish_rejects_missing_duplicate_and_attempted_calls` 等）。

所以大概率是「做完没勾」，不是「没做完」。但状态与验收不一致本身就是待核实项：关闭应当以验收真实完成为前提，未核对就关闭等于把核实责任推给下一个人。这三个验收项里还有两条是**约束型**的（「公共接口里没有更新或删除」「没有入参正文列」「审计库不可用时 fail-open」，与「fail-closed」并存），靠跑一遍测试证明不了，必须读代码确认。
