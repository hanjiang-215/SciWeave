# 根任务不自动派发并实现显式分派

## What to build

没有上游依赖的根 TaskNode 只能由 PO 显式分派，不能因为「没有任何前置条件不满足」就自动开工。同时补上 `dispatch_root_task` 这条路径——它在 `src/` 和 `tests/` 里都还不存在。

规格见 [`2026-10-26-handoff-coordinator-dispatch-defect-fix-design.md`](../docs/superpowers/specs/2026-10-26-handoff-coordinator-dispatch-defect-fix-design.md)。

## Acceptance Criteria

- [x] 无入边根节点在任意正式版本发布后不自动派发，不产生 `task_handoff_ready`。
- [x] 根节点在自动重算路径下留下 `waiting` 事实，而不是被跳过到无从观察。
- [x] 实现 `dispatch_root_task`，可显式派发指定根节点，产出与自动派发形状相同的 `task_handoff_ready`。
- [x] `dispatch_root_task` 幂等：同一根节点重复调用只产生 1 条 dispatch 与 1 条消息。
- [x] 对有入边的非根节点调用 `dispatch_root_task` 时被拒绝，不改动任何状态。
- [x] 新增测试：根节点不自动派发、显式派发成功、重复调用幂等、对非根节点被拒；前两项在修复前失败。
