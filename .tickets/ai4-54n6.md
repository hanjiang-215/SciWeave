# 非法输入与不可重试失败

## Parent

[email-service 通知意图协议与投递状态规格](ai4-f985.md)

## What to build

调用方提交不能发送的通知时，邮件服务把结果记成可查询的终态，并且不发信、也不自动重试。封套非法、通知类型未配置、联系人缺失或禁用、地址不一致、调用方试图覆盖发件信息、正文含凭据或 HTML，都走这条路径。投递记录写不进去时返回 `storage_unavailable`，并且不发信。

## Acceptance criteria

- [ ] 缺少必填字段、未配置的 `notification_kind`、HTML、附件、超限正文或敏感内容进入 `invalid` 或 `permanent_failure`，可查询，且 Fake sender 不被调用，也不会自动重试。
- [ ] 联系人缺失、禁用或调用方地址与登记不一致时，记录不可重试错误，不发信。
- [ ] 调用方传入 From、SMTP 地址或凭据时被拒绝，服务继续使用自己的环境配置。
- [ ] 持久化失败返回 `storage_unavailable`，并且不发信。
- [ ] 上述行为通过认证后的 MCP 调用和 Fake Resolver、Fake sender 验证。
- [ ] 完成测试，并把验证证据回写本票。
