# 验证命令

每个子项目独立验证，命令在该子项目根目录执行。两类 runner 并存，不要混用：`coordinator`、`registry`、`shared/audit-trail`、`shared/message-envelope`、`email-service` 用 pytest（有 `[tool.pytest.ini_options]` 或 `tests/` 下是 pytest 风格函数）；其余用标准库 unittest。用 unittest 的 `discover` 跑 pytest 风格的项目会得到 `Ran 0 tests`，看起来通过但什么都没验证。

## 命令

| 子项目 | 命令 |
| --- | --- |
| `sci-weave/centre-control/coordinator` | `uv run --env-file .env.example pytest -q` |
| `sci-weave/centre-control/research-map` | `uv run --locked python -m unittest discover -s tests -q` |
| `sci-weave/centre-control/research-wiki` | `uv run --locked python -m unittest discover -s tests -q` |
| `sci-weave/centre-control/buffer` | `uv run --locked python -m unittest discover -s tests -q` |
| `sci-weave/centre-control/registry` | `uv run --locked pytest -q` |
| `sci-weave/centre-control/email-service` | `uv run --locked pytest -q` |
| `sci-weave/centre-control/dashboard-api` | `uv run --locked python -m unittest discover -s tests -q` |
| `sci-weave/centre-control/shared/audit-trail` | `uv run --locked pytest -q` |
| `sci-weave/centre-control/shared/message-envelope` | `uv run --locked pytest -q` |
| `sci-weave/centre-control/centre-agents/gateway/mcp` | `uv run python -m unittest discover -s tests -q` |
| `sci-weave/centre-control/centre-agents/gateway/subscriber` | `uv run python -m unittest discover -s tests -q` |
| `sci-weave/centre-control/centre-agents/gateway/ingest` | `uv run python -m unittest discover -s tests -q` |
| `sci-weave/toolkits/researcher-agent-toolkit/deploy-task-agent/runtime` | `uv run --locked python -m unittest discover -s tests -q` |

需要真实基础设施的用例显式跳过（Redpanda、TerminusDB、Kafka），跳过数在输出里单独列出，不计为失败。
